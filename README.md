# 🐾 HelpfulPet

A pet travel accessories e-commerce website built with Node.js and Express.

## About
HelpfulPet sells travel essentials for cats and dogs — carriers, portable beds,
feeding gear, strollers, and more. This is a school project demo; no real
payments are processed.

## Tech Stack
- **Node.js** — JavaScript runtime
- **Express.js** — Web framework and routing
- **EJS** — Server-side HTML templating
- **Vanilla CSS** — Custom styling with CSS variables
- **localStorage** — Client-side cart persistence

## Features
- Browse and filter products by pet type and category
- Product detail pages with quantity selector
- Add to cart with live toast notifications
- Cart page with quantity editing and order total
- Checkout form with demo payment fields
- Order confirmation with generated order number
- Fully responsive layout

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`
